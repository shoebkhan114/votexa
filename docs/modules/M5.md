## Pehle ye rules (zaroori)

1. Sirf **apne GitHub account** se commit karo.
2. `main` ya `develop` par **kabhi direct commit nahi**. Upload se pehle branch button par `feature/m5-audit-blockchain` dikhna chahiye.
3. **ZIP ko extract** karo. ZIP file upload mat karo (GitHub ZIP unzip nahi karta).
4. Kabhi upload nahi karna: `.env`, `.zip`, `target`, `node_modules`, `*.log`, `*.db`, `*.pem`, keys, real passwords.
5. Poora `m5` folder ek saath upload mat karo. Table ke hisaab se **ek package = ek commit**.
6. Sirf apni files upload karo. Kisi aur ke package ko mat chhedo.
7. Commit ki date badal nahi sakti, isliye jis din kaam karo, usi din commit karo. Portal ki entries bhi real kaam se match honi chahiye.

## Setup (sirf ek baar)

**Step 1: ZIP extract karo**
- Ubuntu: `m5.zip` par right-click > **Extract Here**. Windows: right-click > **Extract All...**
- Ek folder `m5` banega. Andar `votexa-backend`, `votexa-frontend` jaise folders honge.

**Step 2: develop kholo**
1. `https://github.com/shoebkhan114/votexa` kholo.
2. Upar-left branch button (jisme `main` likha hai) dabao > **develop** select karo.

**Step 3: Apni branch banao**
1. Button (ab `develop` dikha raha hoga) dobara dabao.
2. Search box mein type karo: `feature/m5-audit-blockchain`
3. Neeche **Create branch `feature/m5-audit-blockchain` from `develop`** par click karo.
4. Check: button par `feature/m5-audit-blockchain` dikhe, aur URL mein `/tree/feature/m5-audit-blockchain`.

> Agar step 3 mein `main` select tha to branch galat jagah se ban jayegi. `develop` pehle select karna zaroori hai.

## Har upload ka tareeka (folder drag and drop)

1. Table ki "Kahan jana hai" wali jagah par jao. Shortcut URL:
   `https://github.com/shoebkhan114/votexa/upload/feature/m5-audit-blockchain/<PATH>`
   (`<PATH>` ki jagah table ka path likho, jaise `votexa-backend/src/main/java/com/votexa`). Ya Code tab mein folders kholo > **Add file > Upload files**.
2. Files app mein apna extracted folder kholo. Dono windows **side by side** rakho (`Super + Left` aur `Super + Right`).
3. Folder par click karke pakdo aur browser ke upload box mein **drag karke chhodo**. (Upload box ke "choose your files" link se folder select nahi hota, wo sirf files leta hai.)
4. Files ki list `/audit/...` jaise path ke saath dikhni chahiye (folder ka naam ke saath). Sirf file ka naam dikhe to **Cancel** karke dobara drag karo.
5. **Commit changes** heading ke neeche pehle box mein (jisme `Add files via upload` likha hai) table ka commit message likho. Bada description box khaali chhod do.
6. Radio option **Commit directly to the `feature/m5-audit-blockchain` branch** select ho. "Create a new branch..." wala option mat chunna.
7. Green **Commit changes** dabao.
8. Check: package folder aur uski files dikhe.

**Final check commit dabane se pehle:**

| Check | Sahi value |
|---|---|
| URL | `/upload/feature/m5-audit-blockchain/...` (develop nahi) |
| Radio option | `feature/m5-audit-blockchain` |
| Message box | Apna message |
| Files ki list | Folder ke naam ke saath (jaise `/audit/File.java`) |

1. Apni branch par **Add file > Create new file**.
2. Filename box mein poora path type karo, jaise `docs/modules/M5.md`. `/` type karte hi folder ban jaata hai.

## Galtiyan aur unka fix

| Problem | Kya karo |
|---|---|
| Upload page par `develop` ya `main` likha hai | Commit mat karo. **Cancel** karo, apni branch select karke dobara upload karo |
| Sirf files upload ho rahi hain, folder nahi | Folder ko Files app se **drag** karo, "choose your files" se nahi |
| Files folder ke bina `com/votexa/` mein chali gayi | Upload galat hua. Leader ko batao, khud delete mat karo |
| ZIP upload kar di | Commit mat karo. Cancel karke ZIP ko extract karo, phir folder drag karo |
| Invite ya Upload files option nahi dikh raha | `https://github.com/shoebkhan114/votexa/invitations` se invite accept karo |
| `.env` ya koi secret galti se upload ho gaya | **Turant leader ko batao.** Secret change karna padega |
| PR mein conflict dikhe | Leader ko batao, khud kuch mat badlo |
| Branch banate waqt error | Naam exactly copy karo, space ya extra `/` nahi |

Har hafte kam se kam **3 commits, 3 alag din** apne account se. Is guide ke Week 1 aur Week 2 tables mein ye pehle se plan hai.
